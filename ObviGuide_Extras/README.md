# Obvi Guide: Extras

Guides for [Obvi Guide](../ObviGuide) that aren't dungeons, written in its own guide format. They show in the guide
list under **Extras**.

- **Aqual Quintessence**: the Hydraxian Waterlords' quests up to the Aqual Quintessence, for dousing the runes in
  Molten Core.
- **Cozy Sleeping Bag** (Alliance and Horde).
- **Exploration**: a guide per exploration challenge ("Explore Alterac Mountains"), under **Legacy Challenges /
  Adventure / Eastern Kingdoms** and **Kalimdor**, as the game files them. A step per area, in an order that goes
  round the zone; each ticks off once the game counts the area as found, so the areas you have already found are
  passed over. Under **Explorer**, Explore Eastern Kingdoms, Kalimdor and Azeroth list the parts you haven't finished
  yet; click one to open its guide in a tab of its own.
  In the game's legacy challenges window, each of these challenges has a **Guide** button that opens its guide.

## Sources

The guide text is our own. Facts were checked against **Attune** by CixiDelmont (what each unlock takes) and
**QuestieDB** (Forever data: quest givers, objectives and positions). Thanks to their authors.

The exploration guides are made from the game's own data tables (as [wago.tools](https://wago.tools) serves them) by
`tools/exploration.ps1`: run it again after a patch to remake `Exploration.lua`. Each area's spot is the middle of the
patch of map it uncovers, so a few large areas are found before you reach it.
